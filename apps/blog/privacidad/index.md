<article class="page"><p class="eyebrow">Transparencia</p><h1>Privacidad</h1><p>El sitio estático no almacena datos personales. Si enviás una flag, el servicio de validación puede generar un identificador irreversible usando una clave secreta del servidor y tu dirección IP. La IP original no se guarda en la base de datos.</p><p>El identificador sirve únicamente para evitar duplicados y construir el Hall of Fame. Antes de habilitarlo públicamente, completá esta política con responsable, contacto, plazo de conservación y base legal aplicable.</p></article>
